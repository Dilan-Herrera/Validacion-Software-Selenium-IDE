### Descripción:
Este repositorio contiene la suite de pruebas automatizadas realizada para el sitio **SauceDemo**. 
Se validaron los flujos de:
1. Autenticación exitosa (Happy Path).
2. Validación de credenciales erróneas (Negative Testing).
3. Interacción con elementos dinámicos (Carrito de compras).

### Herramientas utilizadas:
* **Selenium IDE** (Extensión de navegador)
* **Microsoft Edge** (Motor Chromium para estabilidad de scripts)

### Cómo ejecutar las pruebas:
1. Instalar la extensión Selenium IDE en Chrome o Edge.
2. Descargar el archivo `.side` de este repositorio.
3. Abrir Selenium IDE y seleccionar "Open an existing project".
4. Seleccionar el archivo `.side` y presionar el botón "Run all tests".
